isoboard is in pre-release beta. Detailed release notes begin with version 1.0. Until then, features and settings can change between builds.

The **Settings** tab → **About** shows your installed **Version**. To update, see [install isoboard](../../getting-started/install/#how-do-i-update-isoboard).
