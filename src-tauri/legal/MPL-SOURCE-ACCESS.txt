MPL Source Access
=================

This app contains components licensed under the Mozilla Public License 2.0.
Their complete, unmodified registry source archives are included in mpl-sources/
next to this file. Each .crate file is a gzip-compressed tar archive. Extract a
copy to a writable folder, for example:

  mkdir source
  tar -xzf cssparser-0.37.0.crate -C source

On macOS, find these files inside isoboard.app: Show Package Contents, then
Contents/Resources/legal. The archives are available offline, at no charge,
without an account or commercial license. MPL-2.0.txt contains the license.
Your rights to these components are governed by MPL-2.0, not by additional
commercial-use restrictions for the surrounding application. The archive hashes
match Cargo.lock; source files were compared with Cargo's local registry copy.
The list conservatively includes cssparser-macros, a build-time dependency.
