The website and video delivery involve requests to the hosting/media services.

| Technology                                                            | Purpose and duration                                                                                                                                                              |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Website pages, locally served fonts and media from media.isoboard.app | Cloudflare delivers the resources requested by your browser and processes connection/security metadata. Browser caching follows HTTP cache settings and your browser controls.    |
| Browser session storage for navigation                                | Remembers navigation/scroll state within the browser session. It is not an advertising or cross-site tracking identifier.                                                         |
| Previously saved appearance preference, if present                    | The site may read an existing preference but does not currently save new ones. It remains until removed through browser site-data controls.                                       |
| Cloudflare Web Analytics, outside the excluded regions below          | Audience and performance measurements; six months of analytics history are available to us. Cloudflare describes the beacon as cookie-free and without local-storage identifiers. |

We have not enabled separate Cloudflare log storage or exports. Its Free-plan
Security Events and Security Analytics history is available for 31 days. These
are dashboard history periods, not guarantees of provider-internal deletion.

Cloudflare Web Analytics is configured with its regional exclusion enabled.
The browser analytics beacon is excluded for connections served through
Cloudflare data centres in the EU, the wider EEA, the United Kingdom and
Switzerland. Elsewhere, the service measures website audience and performance.
Cloudflare describes this analytics service as using neither cookies nor local
storage and not fingerprinting individual visitors. The regional exclusion does
not disable Cloudflare's hosting and security processing.

You may use browser controls to restrict scripts or clear site data, and contact
legal@isoboard.app to object to processing based on legitimate interests. Checkout
runs on Polar's site and may use different technologies. A claim that Web Analytics
uses no cookies does not describe every Cloudflare service or the Polar checkout.
